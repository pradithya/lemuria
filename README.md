# Lemuria

Argo CD Pull Request Automation — inspired by [Atlantis](https://www.runatlantis.io/) for Terraform.

Lemuria enables teams to preview, approve, and sync Argo CD applications through GitHub PR comments. It acts as a bridge between GitHub and Argo CD, providing a GitOps-native workflow where infrastructure changes are reviewed as manifest diffs before deployment.

## Features

- **PR Comment Interface** — Interact via `lemuria plan`, `lemuria sync`, `lemuria unlock`, `lemuria rollback`
- **Auto-diff** — Automatically generate and post manifest diffs when relevant files change
- **Application Locking** — Redis-based distributed locks prevent concurrent syncs to the same application
- **ApplicationSet Support** — Detect and diff applications generated by ApplicationSets (via `ownerReferences`)
- **Multi-source Support** — Handle applications with multiple repository sources
- **Approval Requirements** — Optionally require PR approval before sync (per-app or global)
- **Auto-merge** — Optionally merge PRs after successful sync
- **Rollback** — Revert to a previous deployment with `lemuria rollback --id <history-id>`
- **Web UI** — View locks, application status, and manage users
- **Multiple Auth Methods** — GitHub OAuth, OIDC, and basic auth with RBAC

## Architecture

```
┌─────────────┐     webhook      ┌─────────────┐     REST API    ┌──────────┐
│   GitHub    │ ───────────────> │   Lemuria   │ ──────────────> │ Argo CD  │
│   PR Event  │                  │   Server    │                 │  Server  │
└─────────────┘                  └─────────────┘                 └──────────┘
       ^                               │
       │                               │
       └───────── PR comments ─────────┘
                                       │
                                       v
                                 ┌──────────┐
                                 │  Redis   │
                                 │ (locks & │
                                 │ sessions)│
                                 └──────────┘
```

**How it works:**
1. GitHub sends webhook events (PR opened, comment created, review submitted) to Lemuria
2. Lemuria identifies affected Argo CD applications by matching changed files to configured paths
3. For `plan`: fetches manifests from Argo CD, computes diffs, posts results as PR comments
4. For `sync`: acquires a lock, triggers Argo CD sync, reports status, optionally auto-merges
5. Redis manages distributed locks (7-day TTL) and web UI session state

## Quick Start

### Prerequisites

- Go 1.25+
- Node.js 20+ (for frontend)
- Redis
- Argo CD instance
- GitHub App credentials

### Installation

#### From Source

```bash
git clone https://github.com/pradithya/lemuria.git
cd lemuria
make build            # Builds frontend + backend → bin/lemuria

# Configure
cp config/lemuria.yaml.example lemuria.yaml
# Edit lemuria.yaml with your settings

# Run
./bin/lemuria -config lemuria.yaml
```

#### Docker

```bash
docker build -t lemuria:latest .
docker run -p 4141:4141 -v $(pwd)/lemuria.yaml:/app/config/lemuria.yaml lemuria:latest
```

#### Helm (Kubernetes)

```bash
helm upgrade --install lemuria oci://ghcr.io/pradithya/charts/lemuria \
  --namespace lemuria \
  --create-namespace \
  -f values.yaml
```

The Helm chart includes an optional Redis dependency (Bitnami). See `charts/lemuria/values.yaml` for all options.

## Configuration

### Server Configuration (`lemuria.yaml`)

```yaml
server:
  port: 4141
  host: "0.0.0.0"
  base_url: "https://lemuria.example.com"
  log_level: "info"       # debug, info, warn, error

github:
  webhook_secret: "${GITHUB_WEBHOOK_SECRET}"
  app_id: 12345
  app_private_key: "/path/to/key.pem"

argocd:
  server_url: "https://argocd.example.com"
  token: "${ARGOCD_TOKEN}"
  insecure: false
  diff_mode: "branch"     # "branch" or "live"
  temp_app_timeout: "2m"  # timeout for temporary app manifest rendering

redis:
  address: "localhost:6379"
  password: "${REDIS_PASSWORD}"
  db: 0

defaults:
  autoplan: true
  require_approval: false
  auto_merge: false
  merge_method: "squash"
  delete_source_branch: false
  allowed_repos:
    - "org/repo1"
    - "org/*"

auth:
  enabled: false
  session_secret: "${SESSION_SECRET}"
  session_ttl: "24h"
  cookie_domain: "example.com"
  cookie_secure: true
  default_role: "user"
  github:                  # GitHub OAuth
    client_id: "${GITHUB_OAUTH_CLIENT_ID}"
    client_secret: "${GITHUB_OAUTH_CLIENT_SECRET}"
    allowed_orgs: ["my-org"]
  oidc:                    # Generic OIDC
    name: "My SSO"
    issuer_url: "https://sso.example.com"
    client_id: "${OIDC_CLIENT_ID}"
    client_secret: "${OIDC_CLIENT_SECRET}"
    scopes: ["openid", "profile", "email"]
  basic:                   # Basic auth (dev only)
    users:
      - username: admin
        password: admin
        role: admin
```

Multiple config files can be merged: `./bin/lemuria -config base.yaml -config overrides.yaml`

All config values support `${ENV_VAR}` substitution.

### Repository Configuration (`.lemuria.yaml`)

Place in your repository root to customize behavior per repository:

```yaml
version: 1
autoplan: true
require_approval: true

applications:
  - name: "my-app"
    paths:
      - "apps/my-app/**"
      - "base/**"

  - name: "my-app-*"           # Wildcard for ApplicationSet-generated apps
    paths:
      - "apps/my-app/**"
    applicationset: "my-appset"

sync_requirements:
  - name: "production-*"
    require_approval: true
    allowed_users:
      - "admin"
```

## Commands

All commands are triggered by posting a comment on a GitHub PR.

### `lemuria plan`

Generate and post a diff of what would change if synced.

```
lemuria plan                  # Plan all affected applications
lemuria plan -a my-app        # Plan specific application
lemuria plan --all            # Plan all applications
```

### `lemuria sync`

Trigger Argo CD sync for planned applications.

```
lemuria sync                  # Sync all planned applications
lemuria sync -a my-app        # Sync specific application
lemuria sync --prune          # Enable resource pruning
lemuria sync --dry-run        # Dry-run only
```

### `lemuria unlock`

Release locks and discard plans.

```
lemuria unlock                # Unlock all
lemuria unlock -a my-app      # Unlock specific app
```

### `lemuria rollback`

Revert to a previous deployment.

```
lemuria rollback -a my-app --id 5   # Rollback to history ID 5
```

### `lemuria help`

Show available commands.

## Workflow

1. **Open PR** — Lemuria automatically runs `plan` on affected applications (if `autoplan` is enabled)
2. **Review** — Check the manifest diff posted as a PR comment
3. **Approve** — Get PR approval (if `require_approval` is set)
4. **Sync** — Comment `lemuria sync` to apply changes
5. **Auto-merge** — PR is optionally auto-merged after successful sync
6. **Close/Merge** — Locks are automatically released on PR close or merge

## API Endpoints

### Public Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/webhook` | POST | GitHub webhook receiver (HMAC-validated) |
| `/health` | GET | Health check (always returns 200) |
| `/healthz` | GET | Health check (alias) |
| `/ready` | GET | Readiness check (verifies Redis connectivity) |

### Auth Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/auth/providers` | GET | List available auth providers |
| `/auth/github/login` | GET | Initiate GitHub OAuth flow |
| `/auth/github/callback` | GET | GitHub OAuth callback |
| `/auth/oidc/login` | GET | Initiate OIDC flow |
| `/auth/oidc/callback` | GET | OIDC callback |
| `/auth/basic/login` | POST | Basic auth login |
| `/auth/logout` | POST | Logout (requires auth) |
| `/auth/me` | GET | Current user info (requires auth) |

### API Endpoints (require auth if enabled)

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/status` | GET | Server status |
| `/api/v1/locks` | GET | List all locks |
| `/api/v1/locks/{app}` | DELETE | Force unlock app (admin only) |
| `/api/v1/users` | GET | List users (admin only) |
| `/api/v1/users/{id}/role` | PUT | Update user role (admin only) |
