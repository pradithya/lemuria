# Lemuria

Argo CD Pull Request Automation - inspired by Atlantis for Terraform.

Lemuria enables teams to preview, approve, and sync Argo CD applications through GitHub PR comments.

## Features

- **PR Comment Interface** - Interact via `lemuria plan`, `lemuria sync`, `lemuria unlock`
- **Auto-diff** - Automatically post manifest diffs when relevant files change
- **Application Locking** - Prevent concurrent syncs to the same application
- **ApplicationSet Support** - Detect and diff applications generated by ApplicationSets
- **Multi-source Support** - Handle applications with multiple sources
- **Approval Requirements** - Optionally require PR approval before sync

## Architecture

```
┌─────────────┐     webhook      ┌─────────────┐     REST API    ┌──────────┐
│   GitHub    │ ───────────────> │   Lemuria   │ ──────────────> │ Argo CD  │
│   PR Event  │                  │   Server    │                 │  Server  │
└─────────────┘                  └─────────────┘                 └──────────┘
       ^                               │
       │                               │
       └───────── PR comments ─────────┘
                                       │
                                       v
                                 ┌──────────┐
                                 │  Redis   │
                                 │ (state)  │
                                 └──────────┘
```

## Quick Start

### Prerequisites

- Go 1.22+
- Redis
- Argo CD instance
- GitHub App credentials

### Installation

```bash
# Clone and build
git clone https://github.com/org/lemuria.git
cd lemuria
make build

# Configure
cp config/lemuria.yaml.example lemuria.yaml
# Edit lemuria.yaml with your settings

# Run
./bin/lemuria -config lemuria.yaml
```

### Docker

```bash
docker build -t lemuria:latest .
docker run -p 4141:4141 -v $(pwd)/lemuria.yaml:/app/config/lemuria.yaml lemuria:latest
```

## Configuration

### Server Configuration (`lemuria.yaml`)

```yaml
server:
  port: 4141
  host: "0.0.0.0"

github:
  webhook_secret: "${GITHUB_WEBHOOK_SECRET}"
  app_id: 12345
  app_private_key: "/path/to/key.pem"

argocd:
  server_url: "https://argocd.example.com"
  token: "${ARGOCD_TOKEN}"
  insecure: false

redis:
  address: "localhost:6379"
  password: "${REDIS_PASSWORD}"
  db: 0

defaults:
  autoplan: true
  require_approval: false
  allowed_repos:
    - "org/repo1"
    - "org/*"
```

### Repository Configuration (`.lemuria.yaml`)

Place in your repository root:

```yaml
version: 1
autoplan: true
require_approval: true

applications:
  - name: "my-app"
    paths:
      - "apps/my-app/**"
      - "base/**"

  - name: "my-app-*"
    paths:
      - "apps/my-app/**"
    applicationset: "my-appset"

sync_requirements:
  - name: "production-*"
    require_approval: true
    allowed_users:
      - "admin"
```

## Commands

### `lemuria plan`

Generate and post a diff of what would change if synced.

```
lemuria plan                  # Plan all affected applications
lemuria plan -a my-app        # Plan specific application
lemuria plan --all            # Plan all applications
```

### `lemuria sync`

Trigger Argo CD sync for planned applications.

```
lemuria sync                  # Sync all planned applications
lemuria sync -a my-app        # Sync specific application
lemuria sync --prune          # Enable prune
lemuria sync --dry-run        # Dry-run only
```

### `lemuria unlock`

Release locks and discard plans.

```
lemuria unlock                # Unlock all
lemuria unlock -a my-app      # Unlock specific app
```

### `lemuria help`

Show available commands.

## Workflow

1. **Open PR** - Lemuria automatically runs `plan` on affected applications
2. **Review** - Check the diff posted as a PR comment
3. **Approve** - Get PR approval (if required)
4. **Sync** - Comment `lemuria sync` to apply changes
5. **Merge** - Locks are automatically released on PR close/merge

| `/api/v1/locks` | GET | List all locks |
| `/api/v1/locks/{app}` | DELETE | Force unlock app |
